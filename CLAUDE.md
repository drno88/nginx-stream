# nginx-stream

Публичный установщик прокладки на nginx `stream`: `install.sh`, `README.md` (RU, основной), `README.en.md`.

- Репозиторий **публичный**: ни реальных IP, доменов, паролей, ключей, имён наших серверов. В примерах — только
  `192.0.2.0/24`, `198.51.100.0/24`, `203.0.113.0/24`, `2001:db8::/32`, `example.com`.
- Установщик универсальный: сторонние продукты — только в отдельных рецептах на русском (`antizapret/README.md`),
  из README на них ведёт пункт «Рецепты»; в коде, примерах и `docs/` их нет.
- Источник всех конфигов — `install.sh`. `examples/` генерируются `install.sh --dry-run`, руками не правятся;
  поменял шаблон — перегенерируй примеры тем же коммитом.
- `README.md` и `README.en.md` правятся вместе, содержание одинаковое; так же `docs/details.md` и `docs/details.en.md`.
  README — для неспециалиста: как поставить, что значит каждый вопрос и параметр, частые проблемы. Устройство,
  файлы на сервере, фаервол и «почему так» — в `docs/details*.md`.
- Проверка: `bash -n install.sh`, `shellcheck install.sh`, `--dry-run` всех примеров из `examples/`; поведение на системе —
  только на стенде (чистая ВМ Ubuntu 24.04 / Debian 12). Без стенда не пушить.
- Стенд: `python tools/stand.py run|sh|put|get` (в Git Bash — с `MSYS_NO_PATHCONV=1`); доступ — в
  `SERVER_ACCESS.local.md` (не в git). Одно SSH-подключение на вызов: защита SSH пускает 10 новых в минуту.
